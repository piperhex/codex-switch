# 默认 Codex Home 被内置 GUI 环境覆盖

从内置 Codex GUI 的终端或代理任务启动 Codex Remote 时，新进程可能继承 GUI 的
`CODEX_HOME`。旧实现把它当作外部默认目录，再按路径合并内置 GUI 条目，导致
`settings.json` 中只剩 `codex-gui`，原有默认条目消失。该过程不会删除默认目录中的文件。

启动现在会先记录应用实际使用的内置 GUI 目录，再迁移设置。路径解析忽略指向该目录的
`CODEX_HOME`，回退到用户目录下的 `.codex`；已有目录的等价路径也会被识别。
指向其他目录的自定义 `CODEX_HOME` 继续生效，已配置目录仍有最高优先级。

默认目录、当前目录、全部同步目录及保存设置时的回退使用同一解析逻辑。
升级后的首次启动会通过原有设置迁移补回缺失的默认条目，即使应用版本号没有变化。
内置 GUI 仍不参与外部账号和 Provider 的同步。

  默认路径已被覆盖、空列表、保留自定义目录及停用状态，以及重复归一化。
- 隔离子进程回归传入真实 `CODEX_HOME`，执行路径初始化、设置迁移及运行时初始化，
  验证默认条目恢复、GUI 隔离、所有回退入口及重复启动；正常自定义环境目录一并验证。

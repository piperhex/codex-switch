# Codex GUI 对话展示对照与验收

验收日期：2026-09-08。基线为正在运行的 `http://127.0.0.1:8080/`，Codex CLI 为 0.153.4。
本次读取了当前桌面 ChatGPT/Codex 的真实窗口，打开并展开了 Switch 中已有的天气文件对话，
并在独立测试对话中实际执行了文件新增、再次修改和命令读回。

## 原有差异与本次结果

| 对话细节 | 原有表现 | 本次结果 |
| --- | --- | --- |
| 正文与处理过程 | 中途说明与最终回复使用相同样式，反复显示 Codex 标签 | 按回复阶段区分，过程可折叠，最终回复和用户补充保持可见 |
| 文件修改 | 路径和原始文本 | 逐文件展开，增删颜色、旧/新行号、统计、统一/并排切换、复制 diff |
| 新增、删除、重命名 | 未区分展示 | 按实际变更类型显示；新增文件的原始内容按新增行展示 |
| 同一文件反复修改 | 仅能逐项看原文 | 同时保留每次修改和服务端提供的整轮最终 diff |
| 多轮计划与 diff | 只保留对话末尾的一份状态 | 归属各自轮次，在当前页面会话内缓存，刷新和重开可恢复 |
| 大型 diff | 一次渲染全部内容 | 展开后按 200 行增量显示，可继续展开剩余行，复制仍包含全部内容 |
| 代码块 | 普通文本，无独立操作 | 语言标签、语法高亮、复制、换行；diff 代码块使用差异视图 |
| 命令 | 命令和输出混在一个文本块 | 工作目录、命令、输出、耗时、退出码分别展示，命令与输出可分别复制 |
| 搜索 | 常常只有“搜索网页”或查询摘要 | 查询列表、阅读网址、页面内查找、结果标题、链接和摘要 |
| 工具 | 只选取参数或结果中的一份 JSON | 输入、输出、结构化结果、过程反馈和失败信息分别展示 |
| 图片和音频 | 部分图片只显示附件名 | 支持内联图片、生成结果、工具图片和支持格式的工具音频；图片可放大/重试 |
| 审查意见 | 原始 `::code-comment` 文本 | 标题、说明、文件和行号卡片；代码块中的示例指令保持原样 |
| 文件引用 | 本地路径链接没有操作 | 显示文件引用和复制路径操作；网页链接保持正常打开行为 |
| 等待和上下文整理 | 通用“任务活动” | 明确显示等待、整理上下文、代码审查和协作任务类型 |
| 流式输出与滚动 | 可以跟随输出，离开底部后缺少返回入口 | 保留跟随行为，翻阅历史时不抢滚动，提供“回到最新消息” |

事件结构依据实际安装 CLI 导出的 TypeScript 协议核验；`agentMessage.phase`、文件修改事件和
整轮 diff 的含义同时参照 [OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)。

## 验证记录

- 实际历史：展开天气文件，确认 15 行新增内容，逐行数字、统一/并排切换和复制成功。
- 实际新对话：在独立工作目录新建 `codex-ui-check.txt`，再将 `beta` 替换为 `gamma` 并添加 `delta`；
  新增记录为 +2/−0，后续修改为 +2/−1，整轮最终结果为 +3/−0。运行命令读回通过。
- 实际回复：TypeScript 代码高亮、Markdown 表格及处理过程折叠正确。
- 可重复的事件回放：工具输入/输出、搜索结果、失败、计划、图片、暗色样式、停止和长 diff。
- 持续输出时，历史滚动位置保持在约 493px，内容总高度从 2126px 增至 3034px，diff 操作仍可响应。
- 对话模块 107 项测试通过；桌面端 Vitest 252 项和配置 schema 8 项测试通过。
- 官方 CLI 冒烟测试通过：握手、图片、技能、流式输出、历史恢复、队列、steer 和停止。
- Rust 格式检查、893 项测试（4 项既有忽略项）及 `cargo clippy --all-targets -- -D warnings` 通过。
  Rust 验证在相同基线的独立检出中执行，避免并行 Chrome 插件任务尚未完成的文件影响结果。

## 范围与剩余差异

- 本次修改的是对话前端。8080 的安装版使用嵌入资源，需要重新构建并重启才能切换到新资源；
  验收预览连接了同一个真实后端，没有替换安装版或中断正在运行的代理。
- 仅有本机路径、没有图片数据的旧附件仍显示文件名/路径。尚未增加通用文件读取权限或编辑器打开接口。
- Codex 宿主专有的交互可视化、完整 MCP App 小应用、原生审查侧栏和本地媒体读取不在本次前端实现范围。
- 真实测试使用的运行时没有提供 `update_plan` 工具；计划事件的展示通过协议回放和单元测试验证。
- 服务端历史不会重新发送计划/整轮 diff 通知。本页面会话缓存最多 30 份、总计约 50 万字符；
  无缓存或缓存超限时仍显示服务端历史中实际存在的逐次文件修改，标注为“文件修改记录”。
- 应用当前整体最小宽度为 820px；在该宽度下对话未额外撑宽页面，本次没有改为手机布局。

# Codex Switch 浏览器助手隐私说明

更新日期：2026 年 9 月 20 日

本说明适用于 Codex Switch 浏览器助手 Chrome 扩展，由 Codex Switch 开源项目维护。
扩展需要配合用户安装并启用的 Codex Switch 桌面应用使用。

## 处理哪些信息

扩展按 Codex Switch 发来的任务请求，读取标签页的地址、标题和状态，
获取被操作页面的文字、页面结构、表单内容、操作结果或截图，并执行点击、输入、滚动和导航。
需要排查网页问题时，扩展也会按请求读取页面的控制台日志和错误信息。
这些内容可能包含个人身份信息、通讯内容、财务、健康、位置或身份验证信息，
取决于用户打开的网页、输入的内容和交给助手的任务。
扩展会处理任务中的点击、输入和滚动等操作及其结果，不另行记录用户的日常键盘或鼠标活动。
请勿让助手访问与任务无关的敏感页面。

扩展在浏览器本地保存暂停状态、网站访问设置、授权的网站和浏览器名称；
会话中的授权信息及任务标签组记录保存在浏览器会话存储中。
扩展不读取 Chrome 保存的密码库，不使用广告追踪或访问分析服务。

## 用途与传递方式

上述信息仅用于执行用户要求的浏览器任务、显示连接及权限状态，并将结果交还 Codex Switch。
扩展通过 Chrome Native Messaging 将任务数据传递给本机 Codex Switch。
桌面应用及 Codex 会话可能将网页内容、输入、操作结果、日志或截图发送给用户配置的 AI 模型服务商。
因此，任务数据并非始终仅保留在本机。模型服务商的数据处理和保留规则由其隐私政策及用户配置决定。

扩展不将这些信息出售给第三方，不用于广告、用户画像、信用评估或与浏览器任务无关的用途。
扩展对用户数据的使用遵守 Chrome 应用商店用户数据政策，包括其中的有限使用要求。
扩展没有自行上传网页数据的远程服务器，也不自行建立网页内容、日志或截图的长期档案。
任务结果可能保存在桌面应用的会话记录中，或由用户配置的服务商保留。

## 用户控制

扩展默认可在 Chrome 允许的普通 HTTP/HTTPS 网站上响应任务请求。
用户可以在扩展面板切换为逐个网站询问，撤销已授予的网站权限，或暂停全部浏览器控制。
也可以通过 Chrome 的扩展设置进一步限制网站访问权限、停用或卸载扩展。
暂停或撤销权限会停止正在进行的控制，但不会撤回已经传给桌面应用或模型服务商的数据。

卸载扩展会清除其浏览器本地设置；桌面会话记录需要在桌面应用中另行删除。
如需删除模型服务商保存的数据，请使用该服务商提供的设置或联系渠道。

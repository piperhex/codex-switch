## 简介

国庆出门玩，路上想到的需求，也能随手交给 Codex。

通过手机连接电脑，体验 Codex Switch 内置的 Codex GUI：从手机发出一个网页需求，在电脑上执行，再回到手机查看进度、文件改动和网页成果。

手机负责沟通，电脑负责执行。同一条对话，随时接着做。

远程操作，模型配置照旧：沿用你为对话选择的模型和推理强度，由电脑上的 Codex 执行任务，不会仅因换到手机操作就自动改用低配模型。

使用前，在电脑和手机登录同一个 Codex Switch 账号，连接在线电脑；使用期间请让电脑保持联网，Codex Switch 保持运行，并完成 Codex GUI 所需的模型配置。

项目地址：https://github.com/piperhex/codex-switch
下载地址：https://github.com/piperhex/codex-switch/releases
网页版：https://codex.onepiper.cloud/web/

画面为实际操作演示，等待过程经过剪辑，实际速度取决于网络、模型与任务。本片使用 AI 女声配音，封面含 AI 生成视觉元素；Codex Switch 为社区项目。

这个国庆，电脑继续跑，手机随时接。欢迎体验，也欢迎在评论区分享你的使用场景。

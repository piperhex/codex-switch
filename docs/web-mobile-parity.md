## Web 下载行为

- 下载管理复用电脑端 `downloadBrowse` / `downloadOpen`，以及加密聊天的分块读写协议；电脑需支持这些请求。
- 页面间切换、关闭文件预览不会取消任务。关闭网页后不承诺继续传输，重新打开后可手动继续。
- 文件块及其续传位置在 IndexedDB 中原子保存；恢复时比对文件大小和版本，源文件变更则从头下载。
- 每个任务同时读取一块 256 KiB 数据，最多并行两个任务；逐块校验并沿用直连/中转下载限制。
- 下载完成后点击“保存到设备”，通过浏览器保存。删除操作仅移除此网站内的文件缓存和记录。
- 下载记录按登录账户区分，退出账号、切换电脑或断开连接时暂停正在传输的任务。
- 浏览器清理网站数据也会清理下载缓存；保存到设备的文件不受影响。

## 回归入口

`apps/web/e2e/downloads.pw.ts` 验证刷新续传、完整字节、源文件变更、损坏分块、空文件、跨页面下载、
账号隔离、断连、删除迟到响应和窄屏布局；`chat-parity.pw.ts` 覆盖实际加密聊天连接的文件下载与保存。

`chat-diff.pw.ts` 和 `chat-activities.pw.ts` 覆盖手机/桌面宽度下执行中药丸、完成后的文件列表与操作记录；
`file-preview.pw.ts` 验证 HTML 沙箱和 Markdown；手机组件由 `ChatTurnSummary.test.tsx` 回归。

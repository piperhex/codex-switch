# 手机附件上传进度

手机、Web 和 PC 远程发送照片时，每张缩略图内部显示独立的上传百分比和细进度条，
并在图内提示准备、等待连接和等待确认。输入框上方不再显示整条附件上传提示。
本地文件的上传进度显示在对应文件名旁；图片与文件混合发送时也分别计算。
上传中断时显示重连提示；失败后保留草稿，结束后清除进度。电脑已有文件和插件引用不显示上传进度。

传输 v2 使用电脑的分片接收确认更新进度，重传不重复计数。旧版连接使用实际发出的分片更新进度，
仍需等待电脑响应才清除草稿。进度按每个附件的整百分比更新，不增加轮询或修改线上协议。

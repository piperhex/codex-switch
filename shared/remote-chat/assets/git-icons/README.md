# Git tree image assets

Generated with the built-in `image_gen` tool, then copied into this shared directory.
Used by both native and Web at 20 × 20 logical pixels; original alpha is preserved.
The soft two-layer style replaces the previous outlined icons.

## Folder — `folder-v2.png`

Use case: stylized-concept. Asset type: single transparent PNG icon for a mobile Git file tree, displayed at only 20 CSS pixels. Primary request: a refined soft two-layer folder icon. Front view, perfectly upright, centered on a square transparent canvas. Broad rounded sage green folder front, with a slightly darker desaturated teal back layer and a simple upper-left tab. Use two clean overlapping solid shapes; subtly rounded corners, extremely subtle tonal shading only. No dark outline stroke. The front is fully opaque, no transparent hole. Occupy about 86% of canvas width and 72% height, ample consistent padding. Crisp silhouette readable at 20px. Restrained pastel color, polished minimal mobile productivity UI aesthetic. No text, no glyphs, no decorations, no floating badge, no drop shadow, no white background, no checkerboard. Background must be genuine alpha transparency.

## File — `file-v2.png`

Use case: stylized-concept. Asset type: single transparent PNG icon for a mobile Git file tree, displayed at only 20 CSS pixels. Primary request: a refined soft two-layer document icon matching a pastel sage two-layer folder. Front view, perfectly upright, centered on a square transparent canvas. One broad rounded pale blue-gray document sheet, with a slightly darker desaturated steel-blue second sheet offset subtly behind to the upper right; a single small folded upper-right corner. Two short understated blue-gray content strokes on front, generously spaced. No dark outline stroke. Use clean overlapping solid shapes with extremely subtle tonal shading only. Sheet is fully opaque. Occupy about 68% canvas width and 86% height, balanced padding. Crisp silhouette readable at 20px. Polished minimal mobile productivity UI aesthetic. No letters, no text, no decorations, no badge, no drop shadow, no white background, no checkerboard. Background must be genuine alpha transparency.
